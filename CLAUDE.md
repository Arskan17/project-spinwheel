# project-spinwheel

Before working here, read `knowledge/index.md`. It is an OKF v0.2 bundle
(https://github.com/GoogleCloudPlatform/knowledge-catalog/tree/main/okf) with
the architecture, features, decisions, workflows and history of this app.

Keep it current: when you change behaviour, data shapes, storage keys or
workflows, update the matching concept (and its `generated.at`), add an entry
to `knowledge/log.md` (newest first, `## YYYY-MM-DD`), and add new concepts to
the `index.md` of their folder. Every concept needs YAML frontmatter with a
`type`; quote YAML values that contain `?`, `:` or `#`.
